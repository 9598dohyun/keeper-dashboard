# 리드타임용 "첫 응대 시각" 자동화 설정 안내

리드타임(유입 → 첫 응대까지 걸린 시간)을 정확히 잡으려면, 에어테이블에 "첫 응대 시각" 필드를 만들고 자동으로 기록되게 해야 한다. Formula로는 "첫 시점 고정"이 안 되므로 Automation을 쓴다.

**트리거 기준 (확정)**
- 인바운드: `메모 텍스트`가 채워지는 순간 = 첫 응대
- SKB: `[콜]메모 관리`가 채워지는 순간 = 첫 응대

**핵심 원리**: "첫 응대 시각이 비어있을 때만 기록" → 처음 한 번만 찍히고 이후엔 안 바뀐다(그래서 "첫" 응대).

---

## 인바운드 테이블 설정

### 1) 필드 추가
- 인바운드 테이블 → 필드 추가
- 타입: **Date**, 옵션에서 **Include time** 켜기, 12/24시간·타임존은 취향
- 이름: **`첫 응대 시각`**

### 2) Automation 만들기
에어테이블 상단 **Automations** → **+ Create automation** → 이름 예: "인바운드 첫 응대 기록"

**Trigger**: **When record matches conditions**
- Table: 인바운드
- Conditions (AND):
  - `메모 텍스트` — **is not empty**
  - `첫 응대 시각` — **is empty**  ← 이게 "처음 한 번만" 보장

**Action**: **Update record**
- Record: (트리거의 레코드 = Record from step 1)
- Fields to update → `첫 응대 시각`
- 값: **`NOW()`** (수식 입력칸에서 NOW 함수. 또는 "current time" 특수값 제공 시 그것)

→ Turn on.

---

## SKB 테이블 설정

인바운드와 동일하되 트리거 필드만 다르다.

### 1) 필드 추가
- SKB 테이블 → **Date**(Include time) 필드, 이름 **`첫 응대 시각`**

### 2) Automation
- 이름: "SKB 첫 응대 기록"
- **Trigger**: When record matches conditions
  - Table: SKB
  - Conditions (AND):
    - `[콜]메모 관리` — **is not empty**
    - `첫 응대 시각` — **is empty**
- **Action**: Update record → `첫 응대 시각` = **`NOW()`**
- Turn on.

---

## 설정 후 (내가 할 일)

필드가 생기고 데이터가 조금 쌓이면 대시보드에 리드타임을 추가한다:
1. `fetch-airtable.ts`에 `첫 응대 시각` 필드 추가
2. `metrics2`에 **리드타임 = 첫 응대 시각 − 유입시간** 계산 (기존 `computeLeadTimeStats`로 중앙값·6버킷)
3. 대시보드 인바운드·SKB 섹션에 리드타임 표시

**주의**: Automation은 켠 시점 이후 새로 채워지는 건에만 작동한다. 과거 리드는 `첫 응대 시각`이 비어 리드타임에서 제외된다(정상 — 오늘 이후 집계와 일치).
